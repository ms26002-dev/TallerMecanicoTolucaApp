El sistema permitirá administrar la información de clientes, vehículos, empleados, órdenes de trabajo, inventario de repuestos, citas, pagos y facturación, facilitando el control de las actividades del taller y mejorando la atención al cliente. Actualmente, muchos de estos procesos se realizan de forma manual, lo que puede generar errores, pérdida de información y retrasos en el servicio. Con este sistema se pretende centralizar toda la información en una única plataforma, aumentando la eficiencia, la organización y la productividad del negocio. Proceso principal del proyecto El proceso principal del sistema Radiator Springs inicia cuando un cliente llega al taller o agenda una cita para el mantenimiento o reparación de su vehículo. Posteriormente, el empleado registra o consulta la información del cliente y del vehículo, crea una orden de trabajo y asigna el servicio a un mecánico. El mecánico realiza el diagnóstico y la reparación utilizando los repuestos necesarios, mientras el sistema actualiza el estado del servicio y controla el inventario. Una vez finalizado el trabajo, se registra el pago, se genera la factura correspondiente y el historial del servicio queda almacenado para futuras consultas. Este proceso garantiza una gestión ordenada desde la recepción del cliente hasta la entrega del vehículo, proporcionando un mejor control operativo y una atención más eficiente. La comunicación fue buena y cuando surgieron dudas las resolvimos rápidamente, lo que nos permitió avanzar sin muchos retrasos. ¿Qué problemas se tuvieron para poder progresar correctamente en el último Sprint ? Tuvimos algunos inconvenientes porque algunas tareas tomaron más tiempo del que habíamos estimado. También hubo pequeños errores durante el desarrollo que tuvimos que corregir antes de continuar, y en algunos momentos nos faltó organizarnos mejor para repartir el trabajo. ¿Qué hay que mejorar de cara al siguiente sprint ? Para el próximo sprint creo que debemos planificar mejor el tiempo de cada tarea, comunicarnos más seguido sobre el avance de cada integrante y realizar pruebas con mayor frecuencia para detectar errores antes. Así podremos cumplir los objetivos de una forma más organizada y eficiente.
